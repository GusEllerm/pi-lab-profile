# Review round, 13 October 2026: structure, bugs, modularity

Four reviewers in parallel, each with one dimension (architecture and modularity; correctness in
the UI extensions; correctness and safety in the IO extensions; scripts, tests, CI and packaging),
reading the vault notes first so that documented trade-offs were not re-reported. Every finding
ranked here was then traced by hand to the code, and where the claim depended on Pi's behaviour,
into Pi's own source (`agent-session.js`, `session-manager.js`). About 25 candidates; the ones
below survived.

## What was wrong, in order

1. **Spend gate, two holes** (`hpc-bridge.ts`). `applyResult` stamped `at: now` for every hpc
   tool including the `default` branch, so a login-shell call kept a reaped compute block "fresh"
   and the next compute call re-allocated a billed block with no dialog; and `baseOf` returned
   `undefined` for any prefix but the first configured server's, so a second hpc-bridge entry in
   a project `.pi/mcp.json` was ungated. **Handed to another session**; not touched here. The
   hand-off (with the five candidates ruled out: string `confirm_spend`, a throw during the
   dialog, `/reload` desync, parallel calls, headless) is in the session transcript of 13 Oct.
2. **Argo compaction loop** (`argo.ts`). The usage repair summed `getBranch()`, which Pi documents
   as every entry on the path, compacted-away messages included. After the first auto-compaction
   the repaired input read as the full history; Pi's threshold check takes a message's usage at
   face value (`agent-session.js:2474`; its stale-after-compaction guard is only on the estimate
   path), so every later Argo turn compacted again, a metered call each. Fixed: estimate over
   `buildSessionProjection().messages`. `cf871ff`.
3. **`PI_CODING_AGENT_DIR` ignored** by `rounds.ts` and `fleet.ts` (found independently by two
   reviewers). The documented newcomer test read the author's real `rounds.json` and
   `subagents.json`. Fixed with `lib/paths.ts`; a test fails if any extension resolves the
   directory by hand. `cf871ff`.
4. **fleet pinned every finished agent's session** until exit; the three pickers resolved the
   chosen row by label text, so two agents with one description both mapped to the first; the
   column's memo key called `getContextUsage()` (a full re-projection) on every frame; the
   paste-guard left a timer armed across bursts; the round hand-back could clip a fence open;
   `/open` wrote tool output world-readable; subagent activations overwrote the liveness cache.
   All fixed in `f0c30e5`.
5. **CI's weekly job** misread an import failure as "upstream fixed the bug", and tested Pi
   `@latest` only for bug presence. Now the import is settled first and the whole suite runs
   against `@latest`. `595f225`. The pty relay test then showed a real race (Linux discards
   buffered pty output on hangup, marker included); the relay takes `waitpid`'s status instead
   of guessing 1. `7d5ed32`.
6. **The bus protocol had no owner**: names in eight files, payload types imported by nobody,
   a second `SlotState`, a field nothing read, a listener three weeks past its emitter. And the
   shutdown guard (the rule that bit twice on 20 Sept) was six hand copies. Now
   `extensions/lib/bus.ts` and `lib/lifecycle.ts`; the endpoint-label map's three handlers are
   one. `93b8e68`. hpc-bridge joins when the other session is done.
7. **statusbar.ts held ten concerns.** The pure arithmetic (usage, speed, context trail) is
   `lib/metrics.ts` with its own tests, and the context-trail test imports the class instead of
   slicing the file between comment markers. `0d54b49`. 1,673 → 1,504 lines.

## Deferred, with the reasoning

- `lib/compat.ts` (the three upstream workarounds, `/prof`, `/compat`) and `lib/layout.ts`
  (mount/unmount/resize) out of statusbar: clean seams, but the only harness is `tui-smoke.py`
  and a live session; do it after the demo, with the `hover-guard` test converted at the same
  time.
- Lab facts inside generic mechanism (`endpoints.ts`: the ALCF host, Sophia's exclusion list,
  `"globus"` → `"globus3"`, the tunnel hint; `liveness.ts`: priors keyed `mcp__hpc__*`). The
  fix is a per-profile file (probe kind per host, labels, hints, exclusions) that endpoints reads,
  which changes the profile schema: proposed, not done.
- `fmt` diverges between the column (`32k`) and the fleet widget (`31.7k`); a `lib/text.ts`
  would unify, at the cost of changing one of the displays.
- `alcf-token` and `check.sh` time out through `perl`; `globus-tunnel` finds the port's owner
  with `lsof`; on a minimal Linux without either the diagnosis is wrong rather than absent.

## What held up

The `statusbar:ready` replay makes publisher load order irrelevant; every pure core takes its
clock and data as arguments; the once-per-process wrappers through `Symbol.for` solve reload
stacking consistently; every reach into a Pi internal checks shape first and degrades to
"feature off". The reviewers found no stale-ctx path from any timer or continuation -- the
20 Sept rule is holding, and is now a helper rather than a convention.

## Method notes

- A reviewer with one dimension and the vault's notes in front of it does not re-report
  documented trade-offs; without the notes the same reviewers flagged several.
- Confirming into Pi's source was decisive twice (the compaction trigger's two paths; what
  `getBranch()` includes). A reviewer's "CONFIRMED" was right every time it was checked, but the
  check is what makes it usable.
- Two of the fixes' tests were wrong on the first run (the picker numbering, the fence offset,
  the meter's 200 ms floor): the code was right each time. Worth remembering before "fixing" a
  function to match a fresh test.
- One push went out with a failing test because the commit was not gated on the suite; the
  chain now ends with `npm test | grep -q "# fail 0" && git commit`.
